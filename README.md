# 오늘 어디 걸을까 (서울·경기 트래킹 코스 추천)

조건 3개(시간·출발·이동)를 고르면 입문자용 코스 3개를 추천하는 정적 웹앱입니다. 현재 코스는 **샘플 데이터**(가상)입니다.

## 실행
```
cd trekking
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 을 엽니다. (위치 정보는 localhost 또는 HTTPS에서만 동작합니다.)

## 테스트
```
npm test
```

## 지도 키 넣는 법
1. 네이버 클라우드 플랫폼에서 Maps 애플리케이션을 만들고 Web 서비스 URL에 `http://localhost:8000` 을 등록합니다.
2. 발급받은 Client ID를 `config.js`의 `NAVER_MAP_CLIENT_ID`에 넣습니다.
3. 키가 비어 있거나 지도를 불러오지 못하면 **SVG 경로 미리보기**가 대신 보입니다. 앱의 나머지 기능은 키 없이 동작합니다.

> 키가 없어 **실제 네이버 지도에 경로선이 그려지는 부분은 아직 확인하지 못했습니다.** 스크립트 주소의 키 파라미터(`ncpKeyId`)도 발급 후 공식 문서로 다시 확인하세요.

## 길찾기 동작
- 코스 카드에서 `이 코스로 정하기`를 누르면 현재 위치에서 코스 출발점까지의 네이버 지도 길찾기를 엽니다. 이동 칩이 `대중교통`이면 대중교통, `자차`면 자동차 경로입니다.
- **모바일:** 네이버 지도 앱(`nmap://route/...`)을 먼저 열고, 앱이 열리지 않으면 같은 탭에서 웹 길찾기로 이동합니다.
- **PC:** 앱 스킴을 시도하지 않고 웹 길찾기를 새 탭으로 엽니다.
- 위치를 알 수 없으면 도착지만 지정한 길찾기를 열고, 출발지는 지도에서 직접 고르면 됩니다.
- 웹 길찾기 주소 형식(`map.naver.com/p/directions/...`)은 공식 문서에 없어 **미확인**입니다.
