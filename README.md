# 오늘 어디 걸을까 (서울·경기 트래킹 코스 추천)

조건 3개(시간·출발·이동)를 고르면 입문자용 코스 3개를 추천하는 정적 웹앱입니다. 코스 데이터는 한국관광공사 **두루누비**(공공데이터포털) 실제 코스입니다.

## 실행
```
cd trekking
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 을 엽니다. (위치 정보는 localhost 또는 HTTPS에서만 동작합니다.)

## 테스트
```
npm test
```

## 화면 흐름
1. **처음 화면:** 칩 3개를 고르고 `코스 추천받기`. 결과는 (내 위치 선택 시) **현재 위치에서 가까운 순**으로 **10개씩** 나오고 `이전/다음 10개`로 넘깁니다. 내 위치에서 100km를 넘는 코스는 제외합니다.
2. **코스 선택 화면:** 카드의 `코스 선택`을 누르면 새 화면이 열립니다.
   - 왼쪽: 네이버 지도에 **코스 전체 경로선**과 출발·도착 마커, 그 아래 코스 정보(거리·시간·난이도·교통편·설명·출처).
   - 오른쪽: **현재 위치 → 코스 출발점** 지도(직선 점선)와 직선 거리, `네이버 지도에서 길찾기` 버튼(이동 칩에 따라 대중교통/자동차 실제 경로를 네이버 지도 앱·웹에서 엽니다).
   - 화면 하단의 `← 처음 화면으로`(또는 브라우저 뒤로 가기)로 돌아가면 이전 결과와 스크롤 위치가 그대로입니다.
3. 오른쪽 점선은 **직선**입니다. 네이버 지도 웹은 다른 사이트 안에 넣을 수 없고(`x-frame-options: DENY`), 실제 도로 경로를 앱 안에 그리려면 Directions API(자동차만 지원, 서버에서 Client Secret 사용)가 필요합니다.

## 지도 설정
- `config.js`의 `NAVER_MAP_CLIENT_ID`에 Client ID가 들어 있습니다(브라우저에 공개되는 값). **Client Secret은 지도 JS API에 필요 없어 코드에 넣지 않았습니다.**
- 네이버 클라우드 콘솔 > Maps 애플리케이션 > Web 서비스 URL에 `http://localhost:8000` 을 등록해야 지도가 뜹니다. 등록 전이거나 인증에 실패하면 SVG 모양과 안내 문구가 대신 나옵니다.

## 즐겨찾기
카드의 ☆를 누르면 브라우저에 저장됩니다(서버 저장 없음). 상단 `★ 즐겨찾기`로 모아 보며, 위치가 있으면 가까운 순입니다.

## 길찾기 동작
- 코스 카드에서 `이 코스로 정하기`를 누르면 현재 위치에서 코스 출발점까지의 네이버 지도 길찾기를 엽니다. 이동 칩이 `대중교통`이면 대중교통, `자차`면 자동차 경로입니다.
- **모바일:** 네이버 지도 앱(`nmap://route/...`)을 먼저 열고, 앱이 열리지 않으면 같은 탭에서 웹 길찾기로 이동합니다.
- **PC:** 앱 스킴을 시도하지 않고 웹 길찾기를 새 탭으로 엽니다.
- 위치를 알 수 없으면 도착지만 지정한 길찾기를 열고, 출발지는 지도에서 직접 고르면 됩니다.
- 웹 길찾기 주소 형식(`map.naver.com/p/directions/...`)은 공식 문서에 없어 **미확인**입니다.

## 코스 데이터 (64개)
- **두루누비 16개** — 한국관광공사 두루누비 정보 서비스(공공데이터포털). 서울·경기의 코리아둘레길(서해랑길, DMZ 평화의 길) 중 난이도 상을 뺀 코스. 대부분 하루 걷는 편도 장거리.
- **오픈스트리트맵 48개** — 서울둘레길(1~21코스 중 대부분), 북한산둘레길 구간, 평화누리길, 늠내길, 안산자락길, 서울로 7017, 명일산책길 등 둘레길·산책로. 서울 36, 경기 12.
  - 길이 1~20km만, 이어지지 않는 경로·등산로·정맥·영문 이름은 제외했습니다.
  - **소요시간은 거리 기준 추정값**(시속 3km)이고, 난이도는 거리로 정했습니다(8km 이하 쉬움, 그 이상 보통).
  - 데이터 © OpenStreetMap contributors, ODbL — 화면 하단에 출처를 표시합니다.
- 시간 칩 기본값은 `상관없음`이라 모든 코스가 가까운 순으로 나옵니다(내 위치 기준 최대 64개).
- 한계: OSM에 등록되지 않은 동네 공원 산책로는 없습니다. 교통편 정보는 두루누비 코스에만 있습니다.
- 갱신:
  - `DURUNUBI_KEY=<인증키> node tools/import-durunubi.js` → `data/courses.js`
  - `node tools/import-osm.js` → `data/courses-osm.js` (공개 서버에 요청 2번)
